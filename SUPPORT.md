# Support

## Where to ask

Use the repository's issue tracker for reproducible defects and documentation
problems. For design proposals, follow [RFC_PROCESS.md](RFC_PROCESS.md). Check
existing issues and documentation before opening a new request.

## What to include

Provide the installed version, operating environment, a minimal reproduction,
expected and actual behavior, and safe logs with secrets and project content
removed. Do not include credentials, customer data, unpublished work, or
security exploit details.

## Boundaries

Support does not include vulnerability disclosure, hosted deployment operation,
Marketplace publication, or custom commercial integrations. Report security
concerns privately under [SECURITY.md](SECURITY.md).
