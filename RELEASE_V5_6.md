# manga-director v5.6.0

Release date: 2026-08-09  
Canonical package and frontend version: `5.6.0`

Manga Production OS v5.6 promotes the RC1-reviewed Story, Character, Page,
Review, and Export Engine reports to the stable maintenance baseline. The
services remain optional, single-page, transport-neutral, and read-only.

No image generation, creative rewrite, automatic review, approval, workflow
transition, export, publication, or repository mutation is added.

## Compatibility

All Python API, CLI, FastAPI/REST, MCP, Web UI, Repository, SDK, and
StateMachine contracts remain compatible. No migration is required; see the
[migration guide](docs/MIGRATION_V5_5_TO_V5_6.md).
