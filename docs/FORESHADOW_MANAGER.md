# Foreshadow Manager

Foreshadow Manager reads optional `foreshadow_context` evidence using two lists:
`setups` and `payoffs`. Each declared payoff must reference a declared setup.
The report also lists unresolved setups for a human editor to resolve or defer.

No setup, payoff, resolution, or story content is created automatically. The
manager exists to make traceability visible before later review and ending work.
