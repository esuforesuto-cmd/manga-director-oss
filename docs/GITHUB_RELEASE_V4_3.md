# GitHub Release Notes — v4.3.0

## manga-director v4.3.0

v4.3.0 promotes the RC1-reviewed Creative Production Platform to a stable
release. Production Pipeline, Asset Management, Project Workspace, Deliverable
Management, Publishing Workflow, Project Operations, Quality Assurance, and
operational reporting remain typed, transport-neutral, exactly-one-Page DTO
projections.

This release preserves all v4.2 and earlier documented Python API, CLI,
FastAPI, REST, MCP, Repository, Workflow, Extension SDK, Provider, Backend,
and Web UI contracts. No migration is required.

The release does not add automatic execution, asset mutation, publishing or
distribution, approval, policy enforcement, monitoring, alerting, recovery,
external service integrations, billing, Cloud services, marketplace, or
distributed runtime.

See the [release notes](../RELEASE_V4_3.md),
[migration guide](MIGRATION_V4_3.md), and
[release-ready report](V4_3_RELEASE_READY_REPORT.md).
