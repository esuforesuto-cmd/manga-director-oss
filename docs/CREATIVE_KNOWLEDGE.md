# Creative Knowledge

Creative Knowledge projects the existing Knowledge Foundation into Character,
World, Story, Scene, and Asset knowledge topics plus a relationship report. It
uses repository-derived project identifiers and metadata keys only. Metadata
values are not exposed, and no new knowledge store or Repository interface is
introduced.

The relationship graph is diagnostic evidence, not a semantic search engine or
shared mutable memory. It contains no workflow authority and has no persistence
side effect.

Delivery: `manga-director director creative-knowledge`, `GET
/v3/creative-knowledge`, `GET /v3/knowledge-relationships`, and MCP tools
`creative_knowledge` / `knowledge_relationship`.
