# Executive Decision Dashboard

`V47DecisionIntelligenceService.executive_decision_dashboard()` composes
Decision Intelligence, Recommendation Analytics, Review Analytics, and Approval
Insights reports into a presentation-independent Executive Decision Dashboard
DTO.

The dashboard is an immutable handoff only. It cannot query, collect, persist,
publish, monitor, alert, enforce, approve, route work, take an organizational
action, or call an external service.
