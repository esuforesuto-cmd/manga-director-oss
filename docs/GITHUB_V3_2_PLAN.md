# GitHub Planning: v3.2

Create a local planning milestone named **v3.2.0 — Creative Studio and
Production Evidence**. This material is import-ready only; it does not create
or modify remote Issues, labels, milestones, projects, or releases.

## Issue Taxonomy

| Type | Purpose | Required evidence |
| --- | --- | --- |
| Epic | Cross-cutting v3.2 planning outcome. | Child Issues, compatibility boundary, owner, rollback plan. |
| Creative Studio | Workspace, session, dashboard, story, page, or review design. | Human ownership and no-execution proof. |
| Asset Intelligence | Catalog, metadata, relationship, search, version, or usage design. | Repository, provenance, retention, redaction, and no-write proof. |
| Workflow Evolution | Template, profile, stage validation, metric, or pipeline design. | StateMachine and one-Page evidence. |
| Production Analytics | Project, quality, review, Knowledge, release, or productivity analysis. | Bounded window, redaction, and no-operation proof. |
| Quality | Architecture, compatibility, benchmark, security, or documentation gate. | Deterministic fixture and acceptance criteria. |
| Documentation / DX | Guide, example, fixture, or contributor aid. | Public-API and mock-only proof. |
