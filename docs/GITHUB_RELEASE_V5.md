# GitHub Release Notes: v5.0.0

## One Creative Platform

v5.0.0 completes One Creative Platform: a compatible, local-first surface for
Unified Context, API, Runtime, SDK, Governance, Observability, Reliability,
Lifecycle, Developer Experience, and Platform Maturity diagnostics.

## Compatibility

v4.8 Python API, CLI, FastAPI/REST, MCP, Web UI, Repository, Workflow, Plugin,
Extension SDK, Provider, and Backend contracts remain supported. No migration
or data conversion is required.

## Important boundaries

This release does not add autonomous execution, workflow mutation, automatic
approval, service routing, dynamic runtime loading, shared persistence,
telemetry, monitoring, policy enforcement, Cloud, billing, marketplace
operation, or distributed runtime.

## LTS-candidate status

v5.0.0 establishes the local diagnostic and compatibility baseline for LTS
consideration. Final LTS publication remains subject to external security,
protected CI, signing, and maintainer approval.
