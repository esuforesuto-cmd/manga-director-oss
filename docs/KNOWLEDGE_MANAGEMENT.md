# Knowledge Management

v2.7 planning considers a Knowledge Repository, index, search, summary,
snapshot, diagnostics, recommendation, and health boundary. Knowledge is
evidence for advisory workflow recommendations; it is never an authority that
overrides the StateMachine, human approval, or persisted workflow artifacts.

Any implementation Issue must define ownership, retention, redaction,
serialization, Repository-port compatibility, deterministic search fixtures,
and failure behavior. Remote retrieval, embedding services, Cloud storage, and
automatic mutation are out of scope for this cycle.
