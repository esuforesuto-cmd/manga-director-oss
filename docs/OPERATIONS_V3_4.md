# v3.4 Operations Guide

Use existing health, diagnostics, observability, reporting, recovery,
configuration validation, and repository integrity operations. Add v3.4
Knowledge Platform, Production Operations, Organization Intelligence, Release
Intelligence, and Governance reports as read-only review inputs.

Capture reports in the deployment record, investigate warnings through the
existing owner-managed process, and retain human approval for workflow and
release decisions. The reports never schedule work, alter data, enforce a
policy, or publish an artifact.
