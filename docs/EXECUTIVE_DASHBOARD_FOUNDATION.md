# Executive Dashboard Foundation

`V47DecisionFoundationService.executive_dashboard()` composes Decision,
Recommendation, Review Intelligence, and Approval Workflow Foundation reports
into a presentation-independent Executive Dashboard DTO.

The dashboard is an immutable handoff to a future adapter. It cannot query or
collect data, persist or publish a dashboard, monitor operations, alert people,
enforce policy, approve a decision, route work, or take an organizational
action.
