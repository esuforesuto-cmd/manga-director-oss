# Creative Memory

Creative Memory is a vocabulary for reading existing evidence across the
creative lifecycle. It does not introduce a memory database or autonomous
retrieval.

| Memory | Intended evidence | Required guard |
| --- | --- | --- |
| Story Memory | Existing plot, chapter, page, and review references. | No story rewrite or persistence. |
| Character Memory | Existing character references and consistency evidence. | No character mutation or scoring authority. |
| World Memory | Existing lore and environment references. | No remote search or merge. |
| Style Memory | Existing style and visual-quality evidence. | No generation or visual replacement. |
| Production Memory | Existing workflow, quality, and reporting references. | No execution, schedule, or retention action. |

Memory identifiers, provenance, redaction, ownership, retention boundaries,
and deterministic fixture behavior must be reviewed before implementation.
