## Issue Taxonomy

| Type | Purpose | Required evidence |
| --- | --- | --- |
| Epic | Cross-cutting v3.4 planning outcome. | Child Issues, compatibility boundary, owner, rollback plan. |
| Knowledge Platform | Catalog, relationship, search, quality, governance, or insight design. | Repository, provenance, redaction, and no-write proof. |
| Production Operations | Dashboard, monitoring, capacity, incident, audit, or analytics design. | Bounded inputs and no-deploy/no-remediation proof. |
| Organization Intelligence | Team, role, workload, collaboration, risk, or confidence design. | Redaction, human review, and no-personnel-action proof. |
| Release Intelligence | Dashboard, metric, deployment, compatibility, regression, or health design. | Release-checklist mapping and no-tag/no-publish proof. |
| Quality / Documentation / DX | Architecture, compatibility, benchmark, security, guide, or fixture work. | Deterministic fixture and acceptance criteria. |
