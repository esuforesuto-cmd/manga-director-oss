# Creative Knowledge Graph Foundation

Creative Graph FoundationはStory Graph、Character Graph、Graph Node、Graph Edge、
Graph Summaryを既存Repository証跡から構成するDTOサービスです。Graphは読み取り
専用であり、保存、マージ、修復、リモート問い合わせ、Repository置換は行いません。

`V4FoundationService.graph()`はProject/Page参照を用いるだけで、既存の
Knowledge Graph、Repository Interface、Workflow Engineを変更しません。
