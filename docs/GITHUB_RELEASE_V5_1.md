# GitHub Release Notes: v5.1.0

## Composable Creative Platform

v5.1.0 completes a local, optional Composition Platform: Capability Registry,
Feature Packs, Platform Profiles, Solution Templates, Composition Engine,
Governance, Observability, Module Lifecycle, Reliability, and typed Unified SDK
previews.

## Compatibility

v5.0 LTS public contracts remain supported across Python API, CLI,
FastAPI/REST, MCP, Web UI, Repository, Workflow, Extension SDK, Provider, and
Backend. No migration is required.

## Safety

Composition remains declarative and human-governed. It does not load modules,
install extensions, invoke services, route runtime work, enforce policy,
collect telemetry, change lifecycle state, recover components, execute
workflows, or approve pages automatically.

See [RELEASE_V5_1.md](../RELEASE_V5_1.md) for release evidence and publication
gates.
