# Collaboration Framework

## Model

Collaboration supports teams and multiple workspaces through explicit
assignment, handoff, review, feedback, and decision records. A collaboration
record references a project and one page; it does not create a competing
workflow state.

## Human-in-the-loop

Director, editor, writer, artist, reviewer, and operator roles may prepare or
review evidence. Only existing approval rules may approve a page. Automated
recommendations are advisory, reversible, and auditable.

## Iteration candidates

- Collaboration Context and membership-reference DTOs.
- Assignment and handoff reports.
- Review decision history and feedback references.
- Workload and coordination analytics with redacted aggregates.
- Role/policy integration without a new identity provider.

## Compatibility

The framework adds no user-management backend, access-control replacement,
remote communication transport, or change to current review commands.
