# Project Governance

Project Governance exposes policy controls for scheduling, allocation, and
delivery commitments alongside observed Project Operations risks. It is an
analysis view, not an operations control plane.

No operation is started and no risk is accepted or mitigated. The service does
not allocate resources, modify schedules, or commit delivery. The immutable
dashboard is available through `director project-governance-v33`,
`GET /v3.3/project-governance`, and MCP `project_governance_v33`.
