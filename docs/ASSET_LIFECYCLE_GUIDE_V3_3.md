# v3.3 Asset Lifecycle Guide

Asset Lifecycle uses the public Repository boundary to summarize asset version,
history, archive, dependency, usage, consistency, health, intelligence, and
governance evidence. Its DTOs are read-only and redacted where appropriate.

The v3.3 services do not add an asset store, alter repository data, retain or
archive content, delete assets, or contact remote services. Perform any
operational change through the existing supported repository workflow.
