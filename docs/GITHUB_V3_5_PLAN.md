## Issue Taxonomy

| Type | Purpose | Required evidence |
| --- | --- | --- |
| Epic | Cross-cutting v3.5 planning outcome. | Child Issues, compatibility boundary, owner, and rollback plan. |
| Unified Knowledge Graph | Graph, relationships, context, traceability, quality, or insight design. | Repository/provenance/redaction/no-write proof. |
| Creative Intelligence | Dashboard, story, character, page-quality, metric, or recommendation design. | Human-review/no-generation/no-approval proof. |
| Production Intelligence | Efficiency, pipeline, capacity, risk, delivery, or operations analysis design. | Bounded input/no-scheduling/no-deploy proof. |
| Platform Analytics | Executive, trend, historical, regression, or health analysis design. | Deterministic fixture/no-collection/no-persistence proof. |
| Quality / Documentation / DX | Architecture, compatibility, benchmark, security, guide, or fixture work. | Acceptance criteria and deterministic evidence. |
