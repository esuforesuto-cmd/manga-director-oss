# Migrating to v3.1.0 RC1

`3.1.0rc1` is backward compatible with v1.x, v2.x, and v3.0 public contracts.
No workflow, configuration, Project-data, Repository, Provider, Image Backend,
Plugin, or Extension SDK migration is required.

1. Install `manga-director==3.1.0rc1` from the approved prerelease artifact.
2. Retain existing configuration, persisted Projects, and database data.
3. Run existing health, repository-integrity, workflow-validation, and release
   readiness checks in the target environment.
4. Adopt v3.1 collaboration, Knowledge, operations, DX, and assurance reports
   only when their advisory projections are useful; none changes execution.
