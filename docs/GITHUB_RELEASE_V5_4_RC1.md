# GitHub Release Notes: v5.4.0 RC1

v5.4.0 RC1 introduces the optional local Creative Quality Framework: Quality
Engine, Review Pipeline, Validation Metrics, Release Criteria, Intelligence,
Governance, Audit, Reliability, Lifecycle, and SDK diagnostics.

It remains fully backward-compatible with v5.0 LTS and v5.3. No automatic
review, CI/CD control, policy enforcement, workflow change, approval, recovery,
or publication is included. This is a pre-release for maintainer and downstream
review; it must not be published without authorized release controls.
