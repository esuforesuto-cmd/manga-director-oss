# v3.5 Unified Knowledge Graph Foundation

The foundation exposes immutable Knowledge Node, Edge, Graph, Context, Trace,
Summary, Report, and Dashboard DTOs from the existing Repository port and one
Page workflow context. Nodes and edges are derived observations, not persisted
graph records; source metadata values are not surfaced.

The service cannot write, merge, repair, search remotely, generate content,
transition a workflow, or approve a Page.
