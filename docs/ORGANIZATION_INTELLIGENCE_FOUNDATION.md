# Organization Intelligence Foundation

v3.4 adds a bounded Organization Intelligence projection for observed team,
role, workload, collaboration, risk, and executive evidence. The values are
derived from Project and workflow shape, not people or external sources.

The service does not score people, make hiring/performance decisions, assign
work, change roles or membership, send notifications, calculate authoritative
delivery confidence, or mutate a Project or workflow.

Use `manga-director director organization-intelligence-v34 --project <id>
--page <number>`, the optional `/v3.4/organization-intelligence` FastAPI
provider, or the `organization_intelligence_v34` MCP tool.
