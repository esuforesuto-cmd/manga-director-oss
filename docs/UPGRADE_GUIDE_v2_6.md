# Upgrade Guide for v2.6.0

v2.6.0 promotes the reviewed RC without changing public APIs, Project data,
workflow semantics, or configuration. No data migration is required from
v2.5.0.

Before accepting a v2.6 implementation Issue, require a compatibility matrix,
configuration impact statement, Repository and workflow migration decision,
rollback plan, deterministic mock tests, documentation updates, and benchmark
evidence where performance is claimed.
