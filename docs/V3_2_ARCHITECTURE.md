# v3.2 Architecture Index

[ARCHITECTURE_V3_2.md](ARCHITECTURE_V3_2.md) records the v3.2 planning boundary
for Creative Studio, Asset Platform, Knowledge Platform, Workflow Intelligence,
Analytics Platform, Operations Platform, and Developer Platform.

The [v3.1 Architecture Summary](ARCHITECTURE_SUMMARY_V3_1.md) remains the
implemented baseline. All v3.2 candidates are optional, immutable,
transport-neutral, and non-executing Application DTO consumers of existing
public ports.
