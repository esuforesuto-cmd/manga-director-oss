# Collaboration Workspace

## v6.0 Iteration 2 foundation

The Collaboration Workspace provides a scoped, immutable view of supplied
assignments for one project and workspace. It reports role coverage and review
requirements without creating assignments, changing memberships, or granting
approvals.

## Compatibility

The report is an opt-in Application-layer addition. Existing collaboration and
workspace data owners, Repository interfaces, delivery APIs, and v5.x behavior
are unchanged.
