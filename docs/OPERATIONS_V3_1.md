# v3.1.0 Operations Guide

Use health, repository integrity, Creative Collaboration, Knowledge Evolution,
Operations Platform, Developer Productivity, Creative Review, observability,
diagnostics, reporting, and Release Readiness as read-only operational evidence.
Reports render as JSON or Markdown but do not schedule work, repair data, choose
a live Provider, or contact external systems.

Before release or deployment, verify repository and workflow context,
configuration, package version, artifacts, documentation, migration guidance,
governance, licenses, and the dependency license report. Hosted CI,
dependency/CVE audit, and secret scan remain publication-time controls.
