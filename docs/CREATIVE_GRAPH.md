# Creative Knowledge Graph

The Creative Knowledge Graph plans typed, Repository-derived views over
existing creative relationships.

| Graph | Scope | Boundary |
| --- | --- | --- |
| Story Graph | Story, chapter, page, and narrative dependencies. | No graph persistence or story edits. |
| Character Graph | Character references and consistency relationships. | No identity mutation or autonomous decision. |
| Asset Graph | Asset metadata and usage relationships. | No asset store, archive, or lifecycle action. |
| Relationship Graph | Cross-domain typed references with provenance. | No merge, repair, or remote query. |
| Timeline Graph | Existing chronology and production evidence. | No scheduling or history retention. |

Graph projections must read through the existing Repository boundaries and
remain redacted, deterministic, explainable, and one-Page scoped where workflow
context is involved.
