# v6.0 Vision: Creative Production Platform

## Vision update

v6.0 evolves manga-director from a one-page Manga Production OS into a
**Creative Production Platform**. The platform coordinates AI-assisted
production, human collaboration, knowledge, multi-project workspaces, and
publication preparation while retaining the v5.x workflow as the source of
truth.

## Product direction

- **AI Native Workflow:** AI produces advisory plans and evidence summaries;
  human review and StateMachine transitions remain explicit.
- **Multi-project and multi-workspace:** portfolio-level context composes
  project references without merging Page workflow state.
- **Collaboration Framework:** assignments, handoffs, review evidence, and
  decisions are traceable across teams.
- **Knowledge Platform:** story, character, world, asset, and production
  knowledge are linked by references with provenance.
- **Enterprise Foundation:** policy, audit, isolation, and operational
  readiness are designed as opt-in capabilities.

## Non-goals

This planning phase adds no autonomous publication, automatic approval,
multi-page workflow execution, cloud deployment, remote marketplace, billing,
or Core Architecture rewrite.

## Compatibility commitment

v5.x Python API, CLI, FastAPI/REST, MCP, Web UI, Repository, Workflow, SDK,
Plugin, and StateMachine contracts remain supported. `6.0.0` is the additive,
stable release; v5.7.0 remains the compatibility baseline.
