# Recommendation Analytics

`V47DecisionIntelligenceService.recommendation_analytics()` provides immutable
rationale, prerequisite, impact, confidence, and comparison readiness fields
for a Recommendation Foundation report. It is a review aid for human decision
owners.

Analytics cannot apply hidden ranking, select an option, accept a
recommendation, grant approval, dispatch work, remediate a finding, create a
schedule, mutate a workflow, or perform an external action.
