# Creative Pipeline Test Plan

- Exercise Story, Manga, Asset, Review, and Publishing plans as DTO-only
  simulations.
- Confirm every page-level plan maps to at most one legal Page action.
- Confirm storyboard evidence precedes image generation proposals.
- Confirm quality review precedes any approval proposal.
- Confirm pipeline pause, escalation, and emergency-stop recommendations make no
  repository or workflow mutation.
