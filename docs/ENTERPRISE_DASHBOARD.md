# Enterprise Dashboard

`V44EnterpriseIntelligenceService.enterprise_dashboard(project_id, context)`
composes Collaboration Intelligence, Portfolio Analytics, Extension
Intelligence, and Marketplace Insights into a transport-neutral Enterprise
Dashboard DTO.

The dashboard is an Application-layer data contract rather than a UI, service,
or monitoring system. It cannot persist or publish a dashboard, trigger action,
allocate work, change a workflow, execute an extension or marketplace entry,
or communicate with a Cloud service.
