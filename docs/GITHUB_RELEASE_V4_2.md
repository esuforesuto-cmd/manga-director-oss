# GitHub Release Notes — v4.2.0

## manga-director v4.2.0

v4.2.0 delivers reviewed Autonomous Creative System foundations for Goal and
Execution planning, Checkpoints, Supervision, Pipeline planning, Governance,
Observability, and Reliability. All additions are typed, transport-neutral,
one-Page DTOs that preserve v4.1 and earlier public contracts.

The release does not add autonomous execution, automatic approval or override,
persistent checkpoints, policy enforcement, monitoring, telemetry export,
retry/recovery execution, Cloud services, or distributed runtime.

No migration is required from v4.1. See the [release notes](../RELEASE_V4_2.md),
[migration guide](MIGRATION_V4_2.md), and
[release-ready report](V4_2_RELEASE_READY_REPORT.md).
