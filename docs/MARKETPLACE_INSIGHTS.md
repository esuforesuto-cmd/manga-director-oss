# Marketplace Insights

`V44EnterpriseIntelligenceService.marketplace_insights(project_id, context)`
returns immutable local catalog insight and readiness DTOs. Every entry remains
exactly-one-Page scoped and human-review-required.

Download, installation, execution, publication, payment, billing, remote
discovery, catalog persistence, and Cloud marketplace operation are all disabled.
The report cannot bypass StateMachine, persisted-storyboard, or completed-quality-review
requirements.
