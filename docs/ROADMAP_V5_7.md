# v5.7 Development Roadmap

v5.7 starts from the v5.6.0 maintenance baseline on the `5.7.x` development
branch. This roadmap is design-only and does not change the installed version.

## Iteration 1 — Platform Foundation

| Issue | Deliverable | Acceptance criteria |
| --- | --- | --- |
| V5.7-01 | Workspace Manager Foundation | Complete: one-page, read-only workspace evidence projection. |
| V5.7-02 | Project Manager Foundation | Complete: existing workflow state and review-evidence projection. |
| V5.7-03 | Asset Manager Foundation | Complete: observed artifact and metadata lifecycle references. |
| V5.7-04 | Automation Foundation | Complete: declarative template/rule evidence with human approval boundary. |
| V5.7-05 | Plugin Runtime Foundation | Complete: read-only existing PluginRegistry contribution inventory. |

## Iteration 2 — Platform Intelligence

| Issue | Deliverable | Acceptance criteria |
| --- | --- | --- |
| V5.7-06 | Production Workspace v2 | Complete: one-page workspace state and asset consistency diagnostics. |
| V5.7-07 | Asset Registry v1 | Complete: deterministic observed lifecycle inventory. |
| V5.7-08 | Workflow and session framework | Complete: StateMachine diagnostics and recovery eligibility reports. |
| V5.7-09 | Resource and Template registries | Complete: caller-supplied capacity and template compatibility validation. |

## Iteration 3 — Governance and Readiness

| Issue | Deliverable | Acceptance criteria |
| --- | --- | --- |
| V5.7-10 | Production Orchestrator | Complete: one-page production-to-export readiness composition. |
| V5.7-11 | Automation and runtime diagnostics | Complete: automation, Event Bus, Task Scheduler, and Snapshot eligibility reports. |
| V5.7-12 | Plugin lifecycle and analytics | Complete: caller-supplied lifecycle inventory and deterministic analytics. |
| V5.7-13 | Release readiness | Pending: v5.6 compatibility, documentation, package, and performance evidence. |

## Won't

No autonomous production, workflow dispatch, automatic approval, asset
publication, Cloud marketplace, remote plugin installation, or Core rewrite is
in scope for v5.7.
