# Enterprise AI Readiness

Enterprise AI readiness is a checklist-only report composed from Director
reliability and Knowledge governance. It reports knowledge deployment,
workflow deployment, configuration, operational, and governance readiness.

The report never deploys, resumes, repairs, configures, or runs a workflow.
Use it as human-review evidence before using the normal, one-page-at-a-time
workflow commands.

Run `manga-director director readiness --project <id> --page <number>` or use
the MCP `enterprise_ai_readiness` tool.
