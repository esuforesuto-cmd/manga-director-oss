# v3.4 Production Operations Guide

Use operations status, capacity, timeline, efficiency, bottleneck,
optimization, and governance DTOs as inputs to human production review. Combine
them with established health, diagnostics, observability, reporting, recovery,
and configuration checks.

The operations surfaces do not monitor remotely, deliver alerts, schedule work,
allocate capacity, change a pipeline, restart a service, remediate an issue, or
deploy an application.
