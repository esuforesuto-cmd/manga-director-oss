# v2.5.0 Operations Guide

Use Production diagnostics, health, repository maintenance, quality automation,
and Release Readiness as read-only operating evidence. Reports can render as
JSON or Markdown but do not schedule work, repair data, select providers, or
contact external systems.

For a release, verify the repository, workflow context, configuration, package
version, artifacts, documentation, migration guidance, governance, license,
and dependency license report. Hosted CI, dependency/CVE audit, and secret scan
remain mandatory publication-time controls.
