# Release Readiness v3.2

Release Readiness projects package version, compatibility evidence, regression
count, quality-gate evidence, production validation, and a human-facing
recommendation. The recommendation never authorizes, tags, publishes, or
deploys a release.

Compatibility validates the additive v3.2 DTO delivery surface alongside the
existing Python API, CLI, FastAPI, MCP, Web UI, Workflow, and Repository
contracts. It does not change any of them.
