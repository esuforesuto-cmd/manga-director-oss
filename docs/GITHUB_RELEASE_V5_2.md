# GitHub Release Notes: v5.2.0

## Creative Automation Framework

v5.2.0 completes optional, local Automation Framework diagnostics: Automation
Engine, Rule Engine, Event Bus, Workflow Templates, Automation Registry,
Intelligence, Governance, Observability, Reliability, Lifecycle, and typed
Unified SDK reports.

## Compatibility

v5.0 LTS and v5.1 public contracts remain supported across Python API, CLI,
FastAPI/REST, MCP, Web UI, Repository, Workflow, Extension SDK, Provider, and
Backend. No migration is required.

## Safety

Automation remains declarative and human-gated. It does not execute a plan,
dispatch an event, queue or schedule work, mutate a workflow, enforce policy,
collect telemetry, transition lifecycle state, recover components, self-learn,
or approve a Page automatically.

See [RELEASE_V5_2.md](../RELEASE_V5_2.md) for release evidence and publication
gates.
