# Creative Memory Foundation

Creative Memory FoundationはStory、Character、World、Style、Production Memoryと
Memory IndexのDTOを、既存の一PageコンテキストとRepositoryメタデータの形だけ
から投影します。メタデータ値は公開せず、Memory Store、永続インデックス、
リモート検索、保持、修正は実装しません。

`V4FoundationService.memory()`の出力は診断専用で、創作判断、Workflow実行、
画像生成、レビュー完了、承認を行いません。
