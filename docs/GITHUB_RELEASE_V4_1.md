# GitHub Release Notes — v4.1.0

## manga-director v4.1.0

v4.1.0 delivers the reviewed Multi-Agent Platform foundations: Agent Registry,
Runtime preparation, Task Planning, Orchestration, Collaboration, Human Review,
Governance, Observability, and Reliability. All additions are typed,
transport-neutral DTOs that preserve v4.0 and earlier public contracts.

The release does not add autonomous agent execution, automatic task dispatch,
approval automation, policy enforcement, message transport, telemetry export,
retry/recovery execution, Cloud services, or distributed runtime.

See the [release notes](../RELEASE_V4_1.md),
[migration guide](MIGRATION_V4_1.md), and
[release-ready report](V4_1_RELEASE_READY_REPORT.md).
