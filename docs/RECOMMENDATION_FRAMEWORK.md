# Recommendation Framework Design

The Recommendation Framework defines advisory, explainable options built from
caller-supplied Decision Engine and Review Intelligence evidence. Each
recommendation states its rationale, evidence references, assumptions,
uncertainty, expected impact, prerequisites, risk, and required human review.

Recommendations are not decisions. The framework cannot rank by hidden policy,
select or accept an option, grant approval, dispatch an agent, change workflow
state, create a schedule, remediate a finding, or call an external system.
