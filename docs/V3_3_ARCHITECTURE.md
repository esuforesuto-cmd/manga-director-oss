# v3.3 Architecture Index

[ARCHITECTURE_V3_3.md](ARCHITECTURE_V3_3.md) records the v3.3 planning boundary
for Production Pipeline, Quality Platform, Asset Lifecycle, Project
Intelligence, Analytics Platform, Operations Platform, and Developer Platform.

The [v3.3 Architecture Summary](ARCHITECTURE_SUMMARY_V3_3.md) records
the implemented release boundary. All v3.3 services are optional,
immutable, transport-neutral, and non-executing Application DTO consumers of
existing public ports.
