# v2.7.0 Knowledge Guide

Knowledge services project existing ProjectRepository data into immutable,
redacted snapshots, searches, relationship graphs, summaries, governance, and
quality reports. The interface is additive and does not create a separate
knowledge store or mutate Repository data.

Use these reports as human-review evidence for planning and operations. Metadata
values, semantic retrieval, retention enforcement, automatic policy changes,
and autonomous workflow decisions are intentionally out of scope.
