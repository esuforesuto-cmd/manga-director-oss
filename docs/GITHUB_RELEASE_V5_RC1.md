# GitHub Release Notes: v5.0.0 RC1

## One Creative Platform Release Candidate

v5.0.0 RC1 prepares the One Creative Platform for final review. It consolidates
the v5 Platform, Context, API Surface, Runtime, SDK, Governance,
Observability, Reliability, Lifecycle, Developer Experience, and Maturity
report layers into an additive, local-first diagnostic surface.

## Compatibility

v4.8 API, CLI, FastAPI/REST, MCP, Web UI, Repository, Workflow, Plugin,
Extension SDK, Provider, and Backend contracts remain compatible. No data
migration is required.

## Important boundaries

This RC does not add autonomous execution, workflow mutation, automatic
approval, service routing, dynamic runtime loading, shared persistence,
telemetry, monitoring, policy enforcement, Cloud, billing, marketplace
operation, or distributed runtime.

## Verification

Local regression, compatibility, integration, static analysis, benchmark,
security, package, documentation, and Unified Platform end-to-end checks are
recorded in the RC assets. A maintainer must review protected CI, sign the tag,
and publish the GitHub pre-release and PyPI artifacts.
