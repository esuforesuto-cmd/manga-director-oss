# GitHub Release Notes - v4.6.0

## Creative Intelligence OS

v4.6.0 is the stable release of the additive Creative Intelligence OS. It
promotes the RC1-reviewed Context, Cross-Agent Memory, Reasoning, Adaptive
Workflow, Intelligence Hub, Governance, Observability, and Reliability DTO
projections without adding runtime automation.

## Highlights

- Human-governed, exactly-one-page-scoped Context, Memory, Reasoning, Workflow,
  Hub, Governance, Observability, and Reliability review evidence.
- Read-only Creative Intelligence analysis and dashboard composition.
- Advisory policy, compliance, audit, and reliability reports.
- No change to StateMachine authority or existing v4.5 public contracts.

## Upgrade

No migration is required from v4.5. Install `manga-director==4.6.0`.
See the [Migration Guide](MIGRATION_V4_6.md) and
[Release Ready Report](V4_6_RELEASE_READY_REPORT.md).

## Validation

The local release suite passed regression, compatibility, Creative Intelligence
end-to-end, benchmark, security-boundary, package, documentation, lint, type,
and Web UI type validation. Maintainers must complete exact-tag CI, signing,
hosted scans, and registry publication before publishing this text as a GitHub
release.
