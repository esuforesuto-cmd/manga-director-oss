# v2.1 Roadmap

## Must

| Priority | Item | Reason |
|---|---|---|
| P0 | Restore full CI quality gates | Release confidence and contributor trust. |
| P0 | Complete delivery-adapter contract tests | Preserve workflow and approval safety. |

## Should

| Priority | Item | Reason |
|---|---|---|
| P1 | CLI diagnostics and database command completion | Improve operational DX. |
| P1 | Extension SDK tests and examples | Make the public extension surface reliable. |
| P1 | Notification/Security delivery integration | Complete already-designed boundaries. |

## Could

| Priority | Item | Reason |
|---|---|---|
| P2 | Prompt/LLM/image repository caches | Reduce repeated work after measurement. |
| P2 | Query and batch planning benchmarks | Establish evidence before optimization. |

## Won't (v2.1)

Marketplace, remote extension download, signatures, distributed queues,
parallel execution, OAuth/JWT, and real-time collaboration. These expand the
trust boundary and require separate design approval.
