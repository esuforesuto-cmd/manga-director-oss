# GitHub Release Notes - v4.8.0

## Creative Operating System complete

v4.8.0 is the stable completion release for the v4 Creative Operating System.
It promotes the RC1-reviewed Unified Platform, Modular Runtime, Unified API
Surface, Operational Intelligence, Lifecycle Management, Governance,
Observability, and Reliability reports without adding runtime automation.

## Highlights

- Unified project/one-Page platform scope, service metadata, lifecycle, and
  transport-neutral dashboard composition.
- Deterministic platform, service, operational, and lifecycle analysis.
- Human-reviewed governance, observability, and reliability evidence.
- No change to StateMachine authority, existing Runtime, or v4.7 public
  contracts.

## Upgrade

No migration is required from v4.7. Install `manga-director==4.8.0`.
See the [Migration Guide](MIGRATION_V4_8.md) and
[Release Ready Report](V4_8_RELEASE_READY_REPORT.md).

## Validation

The local release suite passed regression, compatibility, Creative Operating
System end-to-end, benchmark, security-boundary, package, documentation, lint,
type, and Web UI validation. Maintainers must complete exact-tag CI, signing,
hosted scans, and registry publication before publishing this text as a GitHub
release.
