# GitHub Planning: v3

Create a local planning milestone named **v3.0.0 — Manga Production OS
Foundation**. This is an import-ready planning source only; it does not create
or modify GitHub Issues, labels, milestones, or releases.

## Issue taxonomy

| Type | Purpose | Required evidence |
| --- | --- | --- |
| Epic | Cross-cutting v3 outcome. | Child Issues, compatibility boundary, owner, rollback plan. |
| Feature | Additive advisory capability. | DTO contract, tests, docs, and no-execution proof. |
| Workflow | Director, planning, creative, or review analysis. | StateMachine-derived one-Page evidence. |
| Knowledge | Derived evidence, graph, search, or governance capability. | Provenance, redaction, retention, repository-port proof. |
| Automation | Non-executing planning or simulation. | Human checkpoint and no-dispatch evidence. |
| Enterprise | Governance, operations, or policy guidance. | Security, ownership, and diagnostic evidence. |
| Performance | Read-only planning / lookup measurement. | Reproducible baseline and no live-provider dependency. |
| Reliability | Consistency, integrity, and failure-isolation design. | Fault model and deterministic fixture. |
| Documentation | Design or contributor content. | Audience, links, review owner. |
| Developer Experience | Safe preview and local tooling improvement. | Mock-only command or example evidence. |

## Initial epics

1. **V3-E01 — AI Director Platform:** planning, goals, task graphs, decision
   traces, execution/review strategies, and iteration proposals.
2. **V3-E02 — Knowledge-driven Workflow:** governed project projections,
   relationship graph, search, memory, health, and recommendations.
3. **V3-E03 — Creative Pipeline:** story-through-quality planning, hand-offs,
   asset evidence, and review checkpoints.
4. **V3-E04 — Multi-Agent Collaboration:** capability catalog, coordinator
   graph, conflict policy, and simulation design.
5. **V3-E05 — Compatibility and Quality:** architecture, compatibility,
   benchmark, documentation, security, and migration evidence.

Recommended labels: `v3`, `director`, `planning`, `knowledge`, `creative`,
`multi-agent`, `review`, `memory`, `workflow`, `compatibility`, `security`,
`documentation`, `benchmark`, and `dx`.

Every Issue must link the relevant IDs in [ROADMAP_v3.md](ROADMAP_v3.md), state
whether it is design-only or implementation-ready, and preserve the v2.7
workflow invariants.
