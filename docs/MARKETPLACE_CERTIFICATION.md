# v6.x Marketplace Certification Standard

## Certification criteria

1. Listing identifiers are unique.
2. Listing type is Extension, workflow template, or solution template.
3. Compatibility is declared as `v5_additive` or `v6_foundation`.
4. Human review is required before owner-controlled publication.
5. The descriptor reports no publication or package installation action.

## Certification boundary

Certification validates local descriptor quality only. It does not sign a
package, grant access, contact a remote Marketplace, install content, or
publish a listing. Those activities remain subject to deployment-owned security
and approval controls.
