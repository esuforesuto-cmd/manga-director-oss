# v2.7 Development Planning Report

## Decision

v2.7 begins as an Issue-driven planning cycle on the v2.6.x development branch.
Core architecture, public API, StateMachine, Repository port, Provider and
Image Backend protocols, and one-page workflow invariants remain fixed.

## Outcomes

- Roadmap, milestone taxonomy, AI Director, Knowledge Management, Workflow
  Orchestration, Automation Planning, upgrade guidance, examples, benchmarks,
  quality gates, and technical-debt positions are documented.
- Candidate work is advisory, deterministic, mock-friendly, and
  presentation-independent until an accepted Issue authorizes implementation.
- Autonomous execution, dispatch, approval, multi-page generation, Cloud SaaS,
  Marketplace, distributed runtime, and Core redesign are excluded.

## Next steps

Create Must Issues first. Each must include a compatibility boundary, security
and ownership evidence, deterministic mock tests, documentation, benchmark plan
where relevant, and rollback criteria before it can move to implementation.
