# v5.2.0 Architecture Summary

v5.2.0 completes an optional Creative Automation Framework above the unchanged
v5.0 LTS and v5.1 platform contracts. Caller-supplied template, rule, event,
and registry metadata flows into advisory Intelligence and operating-quality
reports only.

No Core, StateMachine, WorkflowEngine, Repository, Runtime, FastAPI, MCP, CLI,
or Web UI owner takes on an Automation dependency. No report can execute,
dispatch, persist, route, enforce, monitor, recover, learn, or mutate a
workflow.

See [v5.2 architecture](ARCHITECTURE_V5_2.md),
[Automation Engine Foundation](AUTOMATION_ENGINE_FOUNDATION.md), and
[Automation Governance](AUTOMATION_GOVERNANCE.md).
