# v3.1.0 Workflow Regression Evidence

Local integration and contract suites exercise the established Application-layer
flow: Project -> Story/Chapter/Page/Panel planning -> Creative Review ->
explicit human approval -> Save -> Reload -> Resume. Batch, Automation,
Notification, FastAPI, MCP, Web UI, Knowledge Evolution, Operations, and
Developer Productivity use the existing boundaries.

v3.1 additions are read-only diagnostics. They do not create a second workflow,
skip a stage, generate without a persisted storyboard, approve without a
completed quality review, or accept multiple Page generation.
