# v2.1 Development Planning Report

v2.1 is planned as an issue-driven stabilization cycle. The architecture and
v1-compatible page workflow remain fixed. Work is classified with Must/Should/
Could/Won't priorities, and technical debt is recorded before refactoring.

GitHub labels: `bug`, `feature`, `enhancement`, `documentation`, `performance`,
`security`, `breaking-change`, `good-first-issue`, `help-wanted`, `plugin`,
`extension`, `frontend`, `backend`, `api`, `database`, `workflow`, `agent`,
`llm`, `image`, `notification`, `automation`.

Milestones: v2.1.0 (stabilization), v2.1.1 (maintenance), v2.2 (approved
extensions), and v3 Planning (design only). Performance candidates are parallel
workflow, prompt/LLM/image/repository caches, query optimization, and batch
optimization; none are committed without benchmarking.
