# Creative Studio Planning

Creative Studio is a planning surface for human-owned creative workspaces.
It projects existing Project, Page, review, and planning evidence. It does not
introduce a collaborative write model or a second workflow engine.

| Candidate | Design boundary | Required evidence before implementation |
| --- | --- | --- |
| Workspace Layout | Describe panels and information hierarchy. | Accessibility, redaction, and no-workflow-authority proof. |
| Creative Session | Describe human participants and pending decisions. | Ownership and no-dispatch proof. |
| Project Dashboard | Summarize existing Project/Workflow metrics. | Bounded query and no-mutation proof. |
| Story Workspace | Display story and Knowledge evidence. | Repository-port and provenance policy. |
| Page Workspace | Display exactly one Page and legal next step. | StateMachine-derived scope proof. |
| Review Workspace | Display findings and human decision queue. | No quality pass or approval authority. |

Every candidate remains design-only until accepted as a reviewed Issue.
