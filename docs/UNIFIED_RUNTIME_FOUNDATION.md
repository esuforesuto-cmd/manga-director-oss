# Unified Runtime Foundation

`UnifiedRuntimeFoundationService` publishes static descriptors for Core,
Workspace, Knowledge, Agent Platform, Production, Enterprise, Decision, and
Ecosystem modules. The descriptors make ownership and dependency direction
visible without becoming a runtime controller.

The service cannot dynamically load, activate, route, invoke, schedule, or
replace any module. Existing Provider, Backend, Plugin, Extension SDK, and
Workflow runtime contracts therefore remain unchanged.
