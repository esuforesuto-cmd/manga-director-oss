# v3.4 Knowledge Platform Guide

Use v3.4 catalog, classification, relationship, quality, index, insight, and
governance DTOs to inspect supplied Repository-derived evidence. The platform
is read-only: it does not create a knowledge store, write a record, mutate
metadata, merge knowledge, or change retention.

Review source provenance, redaction, and integrity findings with the existing
repository and governance process. A report is not a policy decision and cannot
override workflow or repository validation.
