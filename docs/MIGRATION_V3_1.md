# Migrating to v3.1.0

v3.1.0 is backward compatible with v1.x, v2.x, and v3.0 public contracts. No
workflow, configuration, Project-data, Repository, database, Provider, Image
Backend, Plugin, or Extension SDK migration is required.

1. Install `manga-director==3.1.0` from the approved artifact.
2. Retain existing configuration, persisted Projects, and database data.
3. Run health, repository-integrity, workflow-validation, and release-readiness
   checks in the target environment.
4. Adopt v3.1 collaboration, Knowledge, operations, DX, and assurance reports
   only where their advisory projections are useful; none changes execution.

v3.1.0 does not introduce autonomous AI, Agent execution, deployment, or
release-authorization behavior.
