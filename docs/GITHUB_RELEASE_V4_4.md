# GitHub Release Notes — v4.4.0

## Enterprise Creative Platform

v4.4.0 is the stable release of the additive Enterprise Creative Platform.
It promotes the RC1-reviewed Enterprise Workspace, Collaboration, Portfolio,
Extension Registry, Marketplace, Governance, and Reliability DTO projections
without adding runtime automation.

## Highlights

- Human-governed, one-Page-scoped Enterprise Workspace and collaboration evidence.
- Read-only Portfolio, Extension Registry, and Marketplace reporting.
- Advisory Governance, Compliance, and Reliability projections.
- No change to StateMachine authority or existing v4.3 public contracts.

## Upgrade

No migration is required from v4.3. Install `manga-director==4.4.0`.
See the [Migration Guide](MIGRATION_V4_4.md) and
[Release Ready Report](V4_4_RELEASE_READY_REPORT.md).

## Validation

The local release suite passed regression, compatibility, Enterprise
end-to-end, benchmark, security-boundary, package, documentation, lint, and
type validation. Maintainers must complete exact-tag CI, signing, hosted scans,
and registry publication before publishing this text as a GitHub release.
