# User & Role Management

`V60CreativeProductionPlatformFoundationService.user_role_management()`
summarizes caller-supplied Collaboration user references and their declared
roles. It sorts unique user IDs deterministically and reports role coverage
for the supplied evidence only.

The report does not provision users, change memberships, replace an identity
provider, grant permissions, assign work, or approve Pages. Existing Agent
roles, Collaboration assignments, Repository interfaces, and StateMachine
authority remain unchanged.
