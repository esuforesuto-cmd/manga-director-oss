# Release Criteria Foundation

`ReleaseCriteriaFoundation` models quality, compatibility, security,
documentation, package, and approval criteria as explicit evidence. It returns
an advisory status and may identify eligibility for an authorized human release
decision.

The foundation cannot sign, tag, upload, publish, approve, or operate CI/CD.
It requires no configuration, repository change, or migration for v5.0 LTS and
v5.3 consumers.
