# Character Engine v1

Character Engine v1 provides the Character Consistency Standard for exactly one
existing Page. It joins supplied character, story, world, and timeline evidence
into a read-only report covering profile, relationships, growth, appearance,
and dialogue voice.

It never rewrites a character, changes an approved setting, generates dialogue,
changes art, persists a registry, or advances the workflow.

## Standard workflow

1. Project the existing character registry and active character context.
2. Verify profile identity, motivation, story, and world evidence.
3. Validate relationship targets against the supplied registry.
4. Validate character-arc goal, stage, and timeline evidence.
5. Check hair, eyes, clothing, and accessories evidence for visual continuity.
6. Check voice style and markers before human dialogue review.

`V56CharacterEngineService.character_engine()` is advisory only and retains all
existing public APIs, repository contracts, and workflow behavior.
