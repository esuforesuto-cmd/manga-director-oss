# Vision v3.5: Unified Creative Intelligence Platform

## Vision Update

v3.5 plans an additive, cross-cutting improvement over the v3.4 Enterprise
Grade Production OSS baseline. It connects knowledge, creative production,
operations, quality, and analysis as explainable local evidence for people.
It is a design cycle; it grants no autonomous AI, workflow execution, approval,
repository mutation, deployment, or publication authority.
The existing StateMachine remains the sole authority for every legal one-Page
workflow transition.

## Unified Knowledge Graph Vision

The graph is a Repository-derived, provenance-aware projection of supplied
knowledge relationships. Context, traceability, quality metrics, and insights
must remain bounded, redacted, read-only, and explainable. It is not a new
knowledge database, vector service, remote search system, or merge engine.

## Creative Intelligence Vision

Creative dashboards, story/character/page-quality metrics, and recommendations
should help a human review existing planning and quality evidence. They must
not generate content, decide creatively, change a storyboard, or approve a
Page.

## Production Intelligence Vision

Efficiency, pipeline, capacity, risk, delivery, and operations evidence should
make constraints visible without scheduling work, allocating resources,
changing a workflow, remediating an incident, or deploying.

## Platform Analytics Vision

Executive, cross-platform, trend, historical, regression, and health reports
should combine supplied local snapshots with transparent assumptions. They must
not collect remotely, persist analytics, establish a performance SLO, or invoke
an external service.

## Migration Strategy

| Stage | Additive outcome | Compatibility rule |
| --- | --- | --- |
| 0 | Freeze v3.4 APIs, fixtures, workflow semantics, and Repository ports. | No Core, state, serialization, or public API change. |
| 1 | Define shared read-only evidence identifiers and provenance vocabulary. | Existing Repository and Knowledge APIs remain canonical. |
| 2 | Define graph, creative, production, and analytics DTO seams independently. | No hidden writes, remote collection, or new execution path. |
| 3 | Admit opt-in implementation Issues one bounded projection at a time. | Preserve all v1.x-v3.4 contracts and one-Page invariants. |
| 4 | Compare deterministic fixtures and document rollback before exposure. | CLI/FastAPI/MCP/Web UI additions remain optional and additive. |

This vision excludes autonomous AI execution, Cloud SaaS, marketplace,
distributed runtime, Core redesign, and breaking changes.
