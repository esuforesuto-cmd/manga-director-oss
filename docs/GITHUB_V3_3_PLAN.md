# GitHub Planning: v3.3

Create a local planning milestone named **v3.3.0 — Integrated Creative
Production Evidence**. This material is import-ready only; it does not create
or modify remote Issues, labels, milestones, projects, or releases.

## Issue Taxonomy

| Type | Purpose | Required evidence |
| --- | --- | --- |
| Epic | Cross-cutting v3.3 planning outcome. | Child Issues, compatibility boundary, owner, rollback plan. |
| Production Pipeline | Template, stage, approval, publishing prerequisite, validation, or metric design. | StateMachine mapping and no-execution proof. |
| Quality Intelligence | Dashboard, metric, review, consistency, regression, or trend design. | Quality/approval isolation and source provenance. |
| Asset Lifecycle | Lifecycle, history, archive policy, graph, audit, or analytics design. | Repository, ownership, retention, redaction, and no-write proof. |
| Project Intelligence | Health, schedule, resource, milestone, risk, or forecast design. | Bounded inputs, assumptions, and no-operation proof. |
| Quality / Documentation / DX | Architecture, compatibility, benchmark, security, guide, or fixture work. | Deterministic fixture and acceptance criteria. |

## Initial Epics

1. **V33-E01 — Production Pipeline:** templates, stage views, approval and
   publishing prerequisites, validation, and metrics.
2. **V33-E02 — Quality Intelligence:** dashboards, review/consistency metrics,
   regression analytics, and trends.
3. **V33-E03 — Asset Lifecycle:** lifecycle, history, archive policy,
   dependency graph, audit, and analytics.
4. **V33-E04 — Project Intelligence:** health, schedule, resource, milestone,
   risk, and delivery forecast reports.
5. **V33-E05 — Compatibility and DX:** quality gates, examples, benchmarks,
   migration evidence, and contributor guidance.
