# GitHub Release Notes - v4.5.0

## Creative Intelligence Ecosystem

v4.5.0 is the stable release of the additive Creative Intelligence Ecosystem.
It promotes the RC1-reviewed Creative Services, Plugin Ecosystem, Workflow
Marketplace, Knowledge Exchange, Federation, Governance, and Reliability DTO
projections without adding runtime automation.

## Highlights

- Human-governed, exactly-one-page-scoped service, plugin, workflow, knowledge,
  federation, and reliability review evidence.
- Read-only Creative Service, Plugin, Marketplace, Knowledge Exchange, and
  Federation analysis.
- Advisory Ecosystem Governance, trust, compliance, and reliability reports.
- No change to StateMachine authority or existing v4.4 public contracts.

## Upgrade

No migration is required from v4.4. Install `manga-director==4.5.0`.
See the [Migration Guide](MIGRATION_V4_5.md) and
[Release Ready Report](V4_5_RELEASE_READY_REPORT.md).

## Validation

The local release suite passed regression, compatibility, Ecosystem end-to-end,
benchmark, security-boundary, package, documentation, lint, and type
validation. Maintainers must complete exact-tag CI, signing, hosted scans, and
registry publication before publishing this text as a GitHub release.
