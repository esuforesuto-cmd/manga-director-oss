# GitHub Planning: v2.7

Create GitHub milestone **v2.7.0 — AI Director Foundation and Knowledge-aware
Workflow** on the v2.6.x development branch. This is import-ready planning
source; it does not create remote GitHub resources.

| Type | Purpose | Required evidence |
| --- | --- | --- |
| Epic | Cross-cutting outcome | measurable result, compatibility boundary, child Issues, owner |
| Feature | Approved additive capability | architecture decision, migration, tests, docs, rollback |
| Automation | Non-executing plan or simulation | approval boundary, no dispatch, audit evidence |
| Workflow | Advisory planning or orchestration | StateMachine-derived next step, one-page proof |
| Knowledge | Bounded knowledge evidence | retention, redaction, deterministic fixture |
| Enterprise | Operations, policy, or compliance evidence | ownership, security, runbook |
| Performance | Measured advisory path | baseline, workload, budget, rollback |
| Reliability | Failure isolation or recovery evidence | fault model and recovery test |
| Documentation | User, operator, or contributor guidance | audience, links, release impact |
| Developer Experience | Contributor productivity | setup impact, command evidence, documentation |

Initial epics: AI Director Foundation; Knowledge Management; Workflow
Orchestration; Enterprise Automation Planning; and Developer Productivity &
Quality. Use one taxonomy label plus area labels such as `director`,
`workflow`, `knowledge`, `automation`, `enterprise`, `security`,
`performance`, `documentation`, and `dx`.
