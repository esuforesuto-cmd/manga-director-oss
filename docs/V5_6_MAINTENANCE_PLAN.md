# v5.6 Maintenance Plan

## Standard maintenance review

1. Run the v5.6 Engine and full regression suites.
2. Run lint, type, package, installation, and documentation checks.
3. Record the local benchmark with its environment and compare it to the v5.6 baseline.
4. Update the technical-debt registry and quality-trend report from executed evidence only.
5. Escalate external CVE, signing, CI, GitHub, and PyPI actions to maintainers.

## v5.7 planning entry criteria

v5.7 planning may begin when the v5.6 maintenance baseline remains compatible,
the release evidence is synchronized, no unresolved critical local defect is
known, and proposed work does not weaken StateMachine authority.
