# AI Workflow Intelligence

v2.6 planning explores workflow intelligence as advisory Application-layer
capabilities. The Workflow Engine, StateMachine, and human approval remain the
only authorities that may advance a Page.

Candidate Issues cover workflow planning, Agent coordination evidence, Prompt
Pipeline diagnostics, workflow diagnostics, execution planning, checkpoint
planning, workflow analytics, and task scheduling design. Any plan must expose
assumptions, recommend at most one legal next Page step, preserve persisted
storyboard and quality prerequisites, and never invoke an Agent directly.

Task scheduling is design-only in v2.6 planning. It cannot create workers,
dispatch jobs, generate multiple pages, bypass approval, or perform autonomous
AI execution.
