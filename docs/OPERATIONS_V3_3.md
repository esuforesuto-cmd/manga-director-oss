# v3.3 Operations Guide

Use existing health, diagnostics, observability, reporting, recovery, and
repository-integrity services for routine operations. Add Production Pipeline,
Quality Intelligence, Asset Lifecycle, Project Intelligence, and Governance
reports to human review packets; they are snapshots, not automation.

For an incident, preserve project state, run repository and configuration
validation, review recovery evidence, and resume only through the existing
StateMachine workflow. Never bypass storyboard or quality-review requirements.
