# v3.4 Architecture Index

[ARCHITECTURE_V3_4.md](ARCHITECTURE_V3_4.md) defines the additive boundary for
Knowledge Platform, Production Operations, Organization Intelligence, Release
Intelligence, Analytics, Operations, and Developer platforms.

All proposed services are optional, immutable, transport-neutral,
non-executing Application DTO consumers of existing public ports. The v3.3
architecture remains the baseline; no Core dependency direction changes.
