# Creative Collaboration Design

## Role model

| Role | Planning responsibility | Required human checkpoint | Prohibited action |
| --- | --- | --- | --- |
| Director Agent | Frame creative objectives and alternatives. | Approve selected strategy. | Execute or approve workflow. |
| Editor Agent | Surface review criteria and consistency evidence. | Confirm editorial finding. | Complete quality review. |
| Writer Agent | Propose story, dialogue, and continuity considerations. | Approve creative change. | Persist or rewrite story. |
| Artist Agent | Describe storyboard and visual constraints. | Confirm persisted storyboard. | Generate image or modify assets. |
| Reviewer Agent | Summarise quality and governance evidence. | Complete existing quality review. | Approve a Page. |

## Collaboration model

1. A human creates a planning context for one existing Page.
2. Role proposals reference bounded Workspace, Memory, Graph, and Quality DTOs.
3. The platform presents alternatives, conflicts, and required approvals.
4. A human accepts, rejects, edits, or defers a proposal.
5. The existing workflow services perform any actual permitted state transition.

The platform never treats consensus as approval. A review role can recommend a
checkpoint but cannot bypass the established quality-review requirement.
