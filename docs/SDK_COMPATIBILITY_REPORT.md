# v6.0 RC1 SDK Compatibility Report

SDK Foundation validates caller-supplied Python, CLI, FastAPI, MCP, and Web UI
capability descriptors. It is additive to existing SDK and public surfaces:
it generates no SDK, publishes no package, and changes no existing API.

The RC integration contract imports v5.7 and v6 SDK-facing production
services together, preserving the v5.x compatibility surface.
