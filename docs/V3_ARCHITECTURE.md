# V3 Architecture Index

The authoritative layer design is [ARCHITECTURE_V3.md](ARCHITECTURE_V3.md).
This index exists because external planning and release references use both
file-name conventions.

The v3 direction is additive: Director, Planning, Knowledge, Creative, Agent,
Review, Memory, and Presentation services return advisory DTOs over the v2.7
ports. The v2 Core, one-page StateMachine workflow, public APIs, and existing
presentation adapters remain unchanged.
