# Extension Intelligence

`V44EnterpriseIntelligenceService.extension_intelligence(project_id, context)`
turns Extension Registry Foundation evidence into immutable capability,
provenance, compatibility, and recommendation DTOs. The default result is
`not_assessed`, with human provenance and compatibility review required.

It cannot discover remotely, persist a registry, load or execute an extension,
grant a permission, enforce isolation, collect telemetry, or alter the existing
Extension SDK.
