# Quality Analytics

Quality Analytics projects existing quality and storyboard evidence into trend,
regression, coverage, consistency, and executive DTOs. It is a diagnostic aid,
not a quality engine or approval mechanism.

The report does not calculate an authoritative score, establish a baseline,
apply remediation, complete review, or authorize approval. The domain state
machine continues to require a completed quality review before a Page can be
approved.

The shared DTO is available through `director quality-analytics-v33`,
`GET /v3.3/quality-analytics`, and MCP `quality_analytics_v33`.
