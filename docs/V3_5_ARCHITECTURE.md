# v3.5 Architecture Index

[ARCHITECTURE_V3_5.md](ARCHITECTURE_V3_5.md) defines the additive boundary for
Unified Knowledge Graph, Creative Intelligence, Production Intelligence,
Platform Analytics, Developer Platform, and Operations Platform.

All proposed services are optional, immutable, transport-neutral,
non-executing DTO consumers of existing public ports. The v3.4 architecture is
the baseline; no Core dependency direction changes.
