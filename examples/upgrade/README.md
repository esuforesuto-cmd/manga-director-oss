# Upgrade Example

Use a non-production copy of a Project to validate an upgrade:

1. Record a redacted configuration snapshot.
2. Run configuration validation and repository integrity checks.
3. Verify Plugin and Extension manifest compatibility.
4. Resume only through the normal Project, Chapter, Batch, or page workflow.

No file migration or direct workflow-state edit is required for v2.5 planning.
See [Upgrade Policy](../../docs/UPGRADE_POLICY.md) and
[v2.4 Migration](../../docs/MIGRATION_V2_4.md).
