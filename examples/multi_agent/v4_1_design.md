# Multi-Agent Planning Example

This example is a design fixture, not executable code.

```text
Page: chapter-01/page-001
Director: propose creative objectives and alternatives
Editor: identify review criteria
Writer: identify story and dialogue considerations
Artist: identify storyboard and visual constraints
Reviewer: summarise quality evidence
Human: accept, edit, reject, or defer every proposal
```

No agent is invoked. The fixture represents one existing Page only and cannot
create an assignment, dispatch a message, change a workflow, generate an
image, complete review, or approve a Page.
