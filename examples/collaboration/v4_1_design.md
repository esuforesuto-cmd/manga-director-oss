# Creative Collaboration Planning Example

This example models a human-led collaboration packet:

1. Read existing Workspace, Memory, Graph, and Quality evidence for one Page.
2. Show Director, Editor, Writer, Artist, and Reviewer proposals with citations.
3. Record a human disposition for each proposal: accept, revise, reject, defer.
4. Route only approved human decisions to existing authoring and StateMachine
   workflows.

The packet is a future DTO design. It has no persistence, network transport,
automatic consensus, creative mutation, review completion, or approval power.
