# Orchestration Planning Example

This design fixture illustrates a non-executing plan for one Page:

| Proposed task | Suggested role | Dependency | Human checkpoint |
| --- | --- | --- | --- |
| Summarise continuity evidence | Writer | Existing Memory projection | Validate citations |
| Surface storyboard constraints | Artist | Persisted storyboard | Confirm storyboard evidence |
| Compare quality signals | Reviewer | Existing Quality projection | Complete existing review if needed |
| Aggregate alternatives | Director | All observations | Choose or defer plan |

Parallelism is represented as a simulation only. No task starts, no message is
sent, no result is written, and no workflow transition is performed.
