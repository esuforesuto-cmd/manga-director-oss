# OSS Sustainability Roadmap

## v6.x LTS

The current roadmap prioritizes regression stability, security maintenance,
documentation quality, contributor review, SDK and Extension compatibility,
Marketplace certification evidence, performance baselines, and technical-debt
tracking. No new platform capability is planned for the LTS line.

## Future planning

Potential post-LTS work must start with an RFC and a versioned roadmap. It must
retain v5.x compatibility or include a separately approved major-version
migration strategy. See [docs/V6_LTS_PLAN.md](docs/V6_LTS_PLAN.md) for the
active maintenance cadence.
